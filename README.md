# devops-lab2

Ćwiczenie z podstaw Git i GitHub.

## Nazwa projektu
DevOps Lab 2

## Cel
Ćwiczenie podstaw Git i GitHub.

## Wykorzystane narzędzia
- Git
- GitHub
- terminal
- Visual Studio Code

## Instrukcja pracy
1. Utworzenie repozytorium na GitHubie
2. Pobranie go na komputer (`git clone`)
3. Sprawdzenie jego stanu (`git status`, `git branch`)
4. Utworzenie gałęzi roboczej `feature/update-readme`
5. Przygotowanie dokumentacji (README.md)
6. Zapisanie zmiany w commicie
7. Wysłanie gałęzi na GitHuba (`git push`)
8. Utworzenie Pull Requesta
9. Code review
10. Połączenie zmiany (merge)
